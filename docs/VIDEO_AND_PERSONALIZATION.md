# Video courses and personalization — version 13 candidate

Adds seven public video-course entries: Stanford CS229 (2018), CS224N (2024), CS231n (official prior-year playlist), MIT 6.S191 (2026), 6.034 (2010), 18.06 (OCW Spring 2010, recordings Fall 1999), and Berkeley CS188 (Spring 2026). The checked CMU Fall 2023 Panopto recordings require login and are labelled accordingly. Official catalog/playlist links were checked on 2026-10-10; individual playback was not certified.

20 of 33 canonical units now offer video selections alongside all original readings. IDs, prerequisites, concepts, checkpoints and minute estimates remain unchanged; durations describe assigned excerpts and tasks, not entire university courses. Resource cards share one component and resolve both course/video URLs from the canonical registry. History remains byte-identical.

`/resources/courses/` is the video catalog. `/learn/personalize/` is an anonymous browser-memory questionnaire preparing profile.json and a detailed Codex request. It performs no network upload or application storage. Submission starts disabled until the client handler attaches. The form is not online AI inference or a path-import API; existing progress imports are unaffected. Goals/background/time/format preferences and optional selected-material names/explicit known units are collected without identity. Important labels remain English-first with Chinese support.

`public/downloads/ai-learning-kit.zip` contains sanitized public website source, input templates, generic examples, an unchanged copy of the installed personalization Skill, validators, instructions and hash manifest. Hosting/Git metadata, dependencies, private inputs and the archive itself are excluded. After extraction the README instructs restoring the downloaded ZIP, creating local Git history (needed by the tracked-source preview tool), and keeping profiles/plans outside source. No remote or deployment is required. To regenerate from reviewed generic source only, run `python3 scripts/package-learning-kit.py --skill /absolute/installed/skill-root`.

Verification: anonymous intake bounds and explicit IDs; seven public video entries and 20 video-backed units; unchanged original unit semantics; archive hashes/whitelist and byte-identical Skill; standalone Skill example validate and preview, then actual npm run verify in both extracted source and personal preview. Root and repository-subpath npm run verify include data/graph/progress/privacy/build checks. Browser controller, Safari layout/fullscreen/touch, media playback and clipboard/download behavior have not been tested in a real browser. No GitHub push or deployment is authorized for this candidate.
